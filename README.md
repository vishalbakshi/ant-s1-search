# ant-s1-search

I wanted a fast way to dig through [Anthropic's S-1](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm), so I built this little search page: type a question (or click the box for some examples) and the PDF jumps to the 5 best passages, highlighted in construction yellow, all running right in your browser ([try it here](https://vishalbakshi.com/ant-s1-search/search.html)). Under the hood it's hybrid search: ColBERT and BM25 results fused with reciprocal rank fusion, then reranked with full-precision ColBERT. None of this exists without a ton of amazing open source, so a huge shout out to: [answerai-colbert-small-v1](https://huggingface.co/answerdotai/answerai-colbert-small-v1) by Benjamin Clavié and Answer.AI, a 33M-parameter model that punches way above its weight; [pylate-rs](https://github.com/lightonai/pylate-rs) from LightOn, which runs it in WebAssembly, built on Hugging Face's [Candle](https://github.com/huggingface/candle); [PyLate](https://github.com/lightonai/pylate) by Antoine Chaffin and Raphaël Sourty; [ColBERT](https://github.com/stanford-futuredata/ColBERT) itself, by Omar Khattab and Matei Zaharia, which started this whole late-interaction thing; Mozilla's [pdf.js](https://github.com/mozilla/pdf.js), which renders the PDF and pulled out every word and its position; [BM25](https://en.wikipedia.org/wiki/Okapi_BM25) from Stephen Robertson and co., and [reciprocal rank fusion](https://plg.uwaterloo.ca/~gvcormac/cormacksigir09-rrf.pdf) from Cormack, Clarke, and Büttcher, still undefeated; [Transformers.js](https://github.com/huggingface/transformers.js), [mxbai-rerank-xsmall](https://huggingface.co/mixedbread-ai/mxbai-rerank-xsmall-v1) from Mixedbread, and [ms-marco-MiniLM](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L-6-v2), which I used to test rerankers; the [Hugging Face Hub](https://huggingface.co) for hosting the models; and SEC EDGAR for putting the filing out there. Built with [Claude Code](https://claude.com/claude-code), and if you want to rebuild the index yourself, `npm install && node scripts/make_pdf.mjs && node scripts/build_index.mjs` does it.

There's also a [summary page](https://vishalbakshi.com/ant-s1-search/scratch/proto/relevance.html) for when you want the big picture without losing the details, after Licklider and Taylor's line about showing "more global information" to answer "questions of relevance and interrelationship." Pick a section in the outline and the top panel tells you what it means for investors and the public: a TLDR Claude built by writing one sentence for each of the filing's 2,688 paragraphs and merging them, with every number traced back to the filing by `check_numbers2.py`. The right column is the whole outline at once, magnified like the macOS Dock at the three sections most related to the one you picked, so you can see where in the filing they sit. Search on that page is the same hybrid search with rerank, run over the paragraphs and their one-sentence summaries, so plain questions like "will they make money?" find the right sections; matches stay dark in the outline and everything else greys out. The ideas come from George Furnas's fisheye views, Bob Spence and Mark Apperley's bifocal display, and [DocWrangler](https://doi.org/10.1145/3746059.3747625) by Shreya Shankar and co. To rebuild its data: `python3 scratch/proto/paratldr_all.py` (the TLDRs, with Claude Code), `python3 scratch/proto/threads.py` (related sections), and `node scratch/proto/build_search.mjs` (the search index).
